# Credits and asset provenance

**Creator:** Justin Nel / Cyberlane. **Project:** Runtime Story SDK, built for the OpenAI × Tokyo AI Game Builder Challenge (Track 2).

Code, tests, tutorials and visual design were developed with OpenAI Codex assistance and reviewed through source inspection, deterministic regression tests and runtime checks. OpenAI models interpret player intentions through the runtime's provider boundary. Authored game rules remain the authority over effects.

Original demo and site artwork was generated with OpenAI image generation, then selected and integrated into the browser renderers. The site's visual direction draws on cinematic game-studio presentation and late-1990s strategy-game interfaces. No Blizzard or Command & Conquer artwork, logos, music or interface files are included.

- [Off Script asset manifest](../examples/off-script/design/demo-assets.json): selected backgrounds and character sheets, with exact hashes and dimensions.
- [Emberwake art direction and provenance](../examples/emberwake/art-direction/): selected fantasy art, animation parts and generation records.
- [Site asset provenance](../site/README.md): original showcase art and optimized derivatives.

The Off Script browser soundtrack and sound effects use procedural Web Audio synthesis. No soundfont or sampled instrument bank is bundled with the demos or SDK. The YouTube competition video is a separate audiovisual work; its soundtrack licensing is tracked separately and is not granted by this repository's MIT license.
